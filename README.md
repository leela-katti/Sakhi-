# 🌸 Sakhi AI — Your Digital Helper

Sakhi AI is a web-based, voice-interactive assistant designed to guide users step-by-step through skill training programs, document verification, and scheme applications in regional languages (Telugu, Hindi, English).

---

## ✨ Features

- **🎙️ Voice Interaction**: Built-in speech-to-text recognition using Web Speech API for hands-free assistance.
- **🗣️ Telugu Voice Guidance**: Text-to-speech feedback tailored for easy understanding.
- **📄 Document Checklist**: Interactive verification steps for basic required documents (Aadhaar, Mobile Number, Bank Account).
- **🚀 Guided Application Workflow**: Step-by-step assistant guiding users through registration and submission processes.
- **🌐 Multilingual Support Interface**: Easy language switching between Telugu, Hindi, and English.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript (Web Speech & SpeechSynthesis APIs)
- **Backend**: Node.js, Express.js
